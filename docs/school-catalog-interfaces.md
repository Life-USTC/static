# 学校课程目录的公开接口

2026-11-20 核对了官网实际使用的请求和匿名响应。下列路径位于 `https://catalog.ustc.edu.cn/api/teach/`，有特别说明的除外。[官网](https://catalog.ustc.edu.cn/)

| 方法与路径 | 可获得的信息 | 采集情况 |
| --- | --- | --- |
| `GET course/search?keyword=…` | 编号、中英文名、单位、有效标记、最近开课学期。显式空关键词取得 14,189 个不同编号，4,393 条为有效。官网交互搜索会过滤无效记录。加常见分页参数仍返回相同全量 | 已采 |
| `POST course/infos` | 课程 ID 与代码，中英文名、开课单位、学分、学时、开课季节、最近开课学期、有效标记、评分制、考核方式、学科类别、课程类别和模块、教学形式、语言、预修要求、中英文简介、教材、参考书、教学大纲。批量返回顺序可以改变，应按代码配对 | 已采 |
| `GET course/public/{分类ID}` | 公共基础课的分组与成员。数学类 ID 43 返回 20 门，包括 `001512`。一个前端入口也可能合并多个分类 ID | 已采 |
| `GET course/department/{单位ID}` | 院系专业课程的分组与成员。页面 `/catalog/208` 请求 91、46、18、43 四个单位，91 有 147 门。ATMS4003 在专业选修分组内。网站入口代码与请求的单位 ID 不同 | 已采 |
| `GET course/quality` | 综合素质课程按单位返回，可见艺术与审美等细分归类。40 组、251 条，其中 108 条标记无效 | 已采 |
| `GET course-substitute-pool/list` | 原课程组、替代课程组、规则 ID，各成员的中英文名、编号、学分和学时。974 条，涉及 821 个不同课程代码。方向与整组成员都影响含义，`001512` 涉及 12 条 | 已采 |
| `GET program/tree` | 院系 → 专业 → 方案。含各层 ID、名称、专业代码、年级、培养类型。20 个院系、140 个专业节点、1,204 份方案，覆盖 2015–2026 级。前端下拉只列所选专业最近六个年级 | 已采 |
| `GET program/info/{方案ID}` | 单份执行计划及其模块树、课程成员、必选属性、建议修读学期、学分和门数要求。2025 级大气科学主修方案 2998 将 ATMS4003 列为专业选修、建议三年级春季修读 | 已采 |
| `GET course-module/info/{模块ID}` | 执行计划页面点「加载更多」时，用模块节点的 `self.public` 获取公共模块子树。2026 级数学方案 3430 引用体育通修模块 554，要求 4 学分、4 门课。公共模块可被多份方案复用 | 已采 |
| `GET department/college-tree` | 单位的 ID、代码、中英文名、是否学院、子单位。实测 56 个根节点。执行计划树的院系数仅代表有方案的院系，统计口径不同 | 已采 |
| `GET semester/list` | 学期 ID、名称、代码、起止日期和 `isLast`。实测 81 个学期。例：421 为 2026 春，461 为 2026 秋 | 已采 |
| `GET major/list/{单位ID}` | 前端包中有声明，当前执行计划使用 `program/tree` 获取专业。对单位 2、59 的匿名请求均返回 HTTP 404 | 未验证为可用数据源 |
| `GET /data/program/{cn或en}/{文件}.html`（站点根路径） | 「培养方案 2013」历史页面的中英文静态文档，可含专业说明、表格和配图。例：`/data/program/cn/001.html`。与现代执行计划接口分属不同来源 | 可作历史资料 |
| `GET lesson/list-for-teach/{学期ID}` | 学期内所有教学班及所属课程，含教师、行政班、校区、总学时、周学时、学分、上课时间地点原文、人数和容量等。461 返回 2,885 个班 | 已采 |
| `POST lesson/infos` | 按学期和班号批量取该班采用的详情资料，包括考核方式、书目、简介、大纲及所属课程 ID。各字段可与课程目录值相同、不同或为空 | 已采。空库默认采当前公布学期，可指定其他学期 |
| `GET timetable-public-all/{YYYY-MM-DD}` | 一天的教室使用情况。响应分 `lessons`、`tmpLessons`、`exams`、`makeupExams`、`tmpExams`、`roomOccupies`。2026-11-20 返回 478 条上课、332 条临时使用、3 条考试。可取楼号、教室名、起止时刻和用途。周视图逐日请求。普通上课行的 `courseId` 实际可为教学班号字符串 | 该日期来源可补；已有教务课表是另一来源 |
| `GET exam/list/{学期ID}` | 关联教学班的考试，包括日期、起止时刻、类型、批次、方式、应考人数、考场及分配人数。461 返回 171 条。例：`MATH1006.12` 在 11 月 15 日 08:30–10:30 有一场考试，3B201、3B202 各分配 65 人 | 已采 |
| `GET general-exam/list/{学期ID}` | 考试页单独加载的另一组考试，包含课程代码、日期、时间、考场、单位和批次等，样本中有补考。461 返回空数组，421 返回 120 条考场记录、119 个考试 ID。同一场 MATH1007 补考有两个考场，各占一行。部分考试日期晚于归属学期，不应据日期重写学期或凭名称硬配教学班 | 可补 |

课程详情请求使用 `{"codes":["ATMS4003"]}`，教学班详情请求使用 `{"semester":421,"codes":["ATMS4003.01"]}`。官网共用详情弹窗，但各学期的考核、教材等值可不同。保留学期、身份与原始空值。[学校课程目录](https://catalog.ustc.edu.cn/catalog/ma) · [开课查询](https://catalog.ustc.edu.cn/query/lesson)
