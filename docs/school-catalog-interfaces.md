# 学校课程目录的公开接口

2026-11-20 对照了 catalog.ustc.edu.cn 的课程目录、开课查询、执行计划、替代查询、教室和考试页面，检查浏览器的实际请求和匿名响应。范围为当日公开前端使用或声明的接口。下表的「已采」指本地 static 采集器，接口计数和样例数均是当日观察值。除特别注明外，路径前缀为 `https://catalog.ustc.edu.cn/api/teach/`。 [官网入口](https://catalog.ustc.edu.cn/) · [本次核对的前端版本](https://catalog.ustc.edu.cn/assets/index-DeAsVxMB.js)

## 同一弹窗里的两种详情

| 查询对象 | HTTP 请求 | 同一门课的实际结果 |
| --- | --- | --- |
| 课程 | `POST course/infos`，JSON 请求体 `{"codes":["ATMS4003"]}` | 返回课程 ID `143129`、代码 `ATMS4003`，不需要选择学期 |
| 教学班 | `POST lesson/infos`，JSON 请求体 `{"codes":["ATMS4003.01"],"semester":421}` | 返回教学班 ID `173702`、班号 `ATMS4003.01`、所属课程 `courseId: 143129`。同一请求用课程代码 `ATMS4003` 得到空数组 |
| 该学期的开课安排 | `GET lesson/list-for-teach/421` | 班号、教师、校区、周次节次教室、已选人数等属于学期列表。选中具体班后，官网另调上一行的详情接口 |

学校把前两种数据交给同一个弹窗。课程态的考核方式、教材、讲义和参考书旁会出现星号，并提示以每学期开课查询为准。公开响应没有给出这些默认值的编制过程或继承来源。ATMS4003 的两种响应都给了 2 学分、40 学时和结构化书目，但课程的旧版教材文字有值，这个教学班的同名字段为 null。学校弹窗还会解析大纲章节、处理简介 HTML、区分出版教材与讲义，并把空预修要求显示成「无」。因此数据中应保留原始空值。 [课程目录](https://catalog.ustc.edu.cn/catalog/ma) · [开课查询](https://catalog.ustc.edu.cn/query/lesson)

## 课程与归类

| 方法和路径 | 可取得的资料和边界 | static |
| --- | --- | --- |
| `GET course/search?keyword=…` | 编号、中英文名、单位、有效标记、最近开课学期。显式空关键词取得 14,189 个不同编号，4,393 条为有效。官网交互搜索会过滤无效记录。加常见分页参数仍返回相同全量 | 已采 |
| `POST course/infos` | 课程 ID 与代码，中英文名、开课单位、学分、学时、开课季节、最近开课学期、有效标记、评分制、考核方式、学科类别、课程类别和模块、教学形式、语言、预修要求、中英文简介、教材、参考书、教学大纲。批量返回顺序可以改变，应按代码配对 | 已采 |
| `GET course/public/{分类ID}` | 公共基础课的分组与成员。数学类 ID 43 返回 20 门，包括 `001512`。一个前端入口也可能合并多个分类 ID | 已采 |
| `GET course/department/{单位ID}` | 院系专业课程的分组与成员。页面 `/catalog/208` 请求 91、46、18、43 四个单位，91 有 147 门。ATMS4003 在专业选修分组内。网站入口代码与请求的单位 ID 不同 | 已采 |
| `GET course/quality` | 综合素质课程按单位返回，可见艺术与审美等细分归类。40 组、251 条，其中 108 条标记无效 | 已采 |
| `GET course-substitute-pool/list` | 原课程组、替代课程组、规则 ID，各成员的中英文名、编号、学分和学时。974 条，涉及 821 个不同课程代码。方向与整组成员都影响含义，`001512` 涉及 12 条 | 已采 |

课程简介与教学大纲是两套字段。ATMS4003 的大纲内有中英文简介、教学目标和基本要求、重难点、章节内容及学时分配；`001512` 有双语简介而大纲为空。书目也有文字版和结构化版，结构化记录可提供作者、ISBN、出版社、版次等。取决于该门课实际填报情况。 [数学类目录](https://catalog.ustc.edu.cn/catalog/ma) · [院系课程目录](https://catalog.ustc.edu.cn/catalog/208) · [综合素质目录](https://catalog.ustc.edu.cn/catalog/quality) · [替代课程查询](https://catalog.ustc.edu.cn/query/substitute)

## 网站能力与采集取舍

- `GET /api/restricted` 是页面启动时的访问状态检查，本次匿名响应为 `{"restricted":false}`。此值描述本次访问环境。
- `/query/calendar` 当前没有加载教学日历数据。学期起止日可取自学期接口；节假日、补哪一天的课和节次时刻另有教务处校历。 [官网教学日历入口](https://catalog.ustc.edu.cn/query/calendar) · [教务处 2026 秋校历](https://www.teach.ustc.edu.cn/calendar/20135.html)
- 对课程本身，现有快照已覆盖课程详情。最有辨识度的增量是「该课在哪个专业、哪一届作为必修或选修，建议何时修」和「它属于哪些目录分组」。以方案或分类作为关系的来源，按实际引用的模块 ID 去重。
- 对具体开课，先从学期列表取教学班号，再按同一学期批量读取教学班详情。对教室，按用户实际查询的日期缓存；取楼号、房间、时段和用途即可，公开占用回包里的申请人及监考人员信息对查房间没有必要。
